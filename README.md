# ✅ To-Do List App

A simple and functional To-Do List application that allows users to manage tasks efficiently. The app supports creating, storing, and persisting tasks using local storage, providing a smooth and practical productivity experience.

---

## 🚀 Features

* ➕ Add new tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 💾 Data persistence using localStorage
* 🔄 Dynamic UI updates without page reload
* ⚡ Fast and lightweight performance

---

## 🧱 Tech Stack

* **Frontend:** JavaScript, HTML, CSS
* **Bundler:** Webpack
* **Storage:** Browser localStorage



Build for production:

```bash id="e9c2f4"

```

## 🌐 Usage

1. Enter a task in the input field
2. Click “Add” to create a task
3. Mark tasks as complete when finished
4. Delete tasks when no longer needed
5. Tasks remain saved even after refreshing the page
